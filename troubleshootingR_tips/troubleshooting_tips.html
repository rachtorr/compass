Tips for troubleshooting code in R

Tip 1: working directories

  • Know what your file is called and where it’s located
  • where are you working out of? Use getwd()
  • did you spell the name right?
  • use projects and save your data and files in the same folder
water <- read.csv("tidy_water_quality_dataset.csv")
Error in `file()`:
! cannot open the connection
getwd()
[1] "C:/Users/rdt47/Documents/GitHub/compass/troubleshootingR_tips"

Fix the ‘cannot open connection’ error by changing path

In the previous example, my dataset was not located in my Documents folder where I was working out of, so it gave me an error. I had to change the path to locate the file.

path_to_file <- "C:/Users/rdt47/Documents/GitHub/K_aviCode/AIHEC2024/tidy_water_quality_dataset.csv"

water <- read.csv(path_to_file)

Tip 3: object not found

If you haven’t created an object or loaded in data, and you try to run a function on it, you will get an error. Check the Environment panel in upper right to see what objects you have.

glimpse(water_tidy)
Error:
! object 'water_tidy' not found

This error is because there is not a dataframe called water_tidy yet.

Tip 4: check your syntax

Syntax is the rules and structures within the writing of code.

  • punctuation: parentheses and brackets
  • operators: for example, when doing conditional, equal to is == and not equal to is !=
  • spelling of functions
  • assigning the correct variables inside of functions, using quotations around strings
  • when using tidyverse, check placement of %>% and when using ggplot, placement of +

Examples of syntax error output

In the line below, we are filtering out a row where the header was captured as an observation, so rather than the ID for a sample location, they have a row of headers. To remove, we want to filter out where sample_location value is “Sample_Location”.

water_filt <- filter(water, sample_location!=Sample_Location)

Tip 5: non-numeric arguments

Can’t do math on data saved as a character. Check the type of the variable you are using with typeof()

mutate(water, yr_mon = year+date)
Error in `mutate()`:
ℹ In argument: `yr_mon = year + date`.
Caused by error in `year + date`:
! non-numeric argument to binary operator
mutate(water, yr_mon = round(date))
Error in `mutate()`:
ℹ In argument: `yr_mon = round(date)`.
Caused by error in `round()`:
! non-numeric argument to mathematical function
typeof(water$date)
[1] "character"

In both examples, the date column is saved as a character and can’t be combined with a number or used in a math function

Debugging your code

If you have a line that includes several functions strung together with %>%, and you have an error but aren’t sure what is causing it, you can break up the steps into separate lines to run. In this example, three functions are used on water_filt and cause an error.

# tidy code combines multiple functions with a pipe %>% 
water_temps = water_filt %>% # our data frame 
  mutate(tempC = (water_temp_F-32)*5/9) %>% # create new column tempC
  select(year, doy, tempC) %>% # select only these columns 
  filter(year>1995) # filter to this year 
Error in `select()`:
! Can't select columns that don't exist.
✖ Column `doy` doesn't exist.

Debugging your code

By separating into steps we can more easily identify what causes the error.

# mutate
water_temps = water_filt %>% 
  mutate(tempC = (water_temp_F-32)*5/9)
# select 
water_temps = water_temps %>% 
  select(year, doy, tempC)
Error in `select()`:
! Can't select columns that don't exist.
✖ Column `doy` doesn't exist.
# filter 
water_temps = water_temps %>% 
   filter(year>1995)

Tips for solving the errors

  1. read through the error. is it a common error that we’ve already discussed? could be a quick fix
  2. read documentation. Use the Help panel
  3. Google it or use chatGPT. Copy and paste to search it, it is likely someone else has seen a similar issue
  4. Simplify it. If you are running a larger chunk, break it up and step through one at a time
  5. Ask a friend!

last tip: take breaks!

sometimes you just need to go do something not on a screen and come back later
